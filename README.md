# agile-simulator
Simulation to model throughput in Carbon vs Silicon vs Mixed teams

## Overview
This repository contains a simulation tool designed to model and compare the throughput of 
Agile development teams composed of humans (Carbon), agents (Silicon), and mixed developers. 
The simulation is considered an experiment and not to provide any serious insights into the efficiency 
and productivity of different team compositions in software development projects at this point.

## Setup

Open a terminal and verify Python is available with `python --version`. You want 3.10 or higher.

To set up the simulation, follow these steps:
1. Clone the repository: `git clone https://github.com/VXCompany/agile-simulator.git`
2. Navigate to the project directory: `cd agile-simulator`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the simulation: `notebook carbon-vs-silicon.ipynb`
